# TERGM_global_arms_trade_1993-2023

Modelling the evolution of the post-Cold War global major weapons transfer network using SIPRI data.

The code files are accompanying the essay "The International Arms Transfers Network 1993-2023: A Sequence of Temporal Exponential Random Graph Models", a 30-pages summary of my Master's thesis (0. Nguyen_2025_summary_global_arms_trade.pdf).

Objects outputs from the scripts were regularly saved as separate .RData files. The most relevant ones are found in the "number_objects" folders. Less important ones were not uploaded, but are available upon request.
